## Introduction
66일만에 습관을 만들어보세요!<br>
런던의 심리학자 Phillippa Lally는 연구를 통해 하나의 습관 형성을 위해서는 66일이 필요하다고 밝혔습니다.

이제부터는 Just66이 습관 형성을 책임질게요!<br>
만들고 싶은 습관을 추가하고 습관 형성을 위한 여정을 66일동안 떠나보세요.
